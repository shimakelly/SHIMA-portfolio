# Portfolio Website

This repository contains a static portfolio website for SHIMA Kelly Guy.

## Local preview

Open `index.html` in a browser, or use a local static server if preferred.

## Deployment

This project is configured for GitHub Pages using a GitHub Actions workflow.

1. Push this repository to GitHub.
2. In the GitHub repository, go to Settings → Pages.
3. Ensure the source is set to GitHub Actions.
4. The deployment workflow will publish the site automatically.
